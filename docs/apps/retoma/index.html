Retoma.

A contractor who sent several quotes last week needs to know whom to call back today. Retoma puts those follow-ups in date order and keeps the next action beside the quote.

Web app with a demo

A walkthrough

  1. Add a quote with an amount, a contact and a follow-up date.
  2. Open the follow-up queue and review the message prepared for that quote.
  3. Contact the customer, then record the outcome or set another follow-up date.

Implementation

The server stores amounts as integer cents and interprets follow-up dates in the São Paulo time zone. The total and due date keep the same meaning when the dashboard is reopened.

Development status

The web app includes a demo with sample quotes. Changes in that demo last for the current session and reset on reload.
