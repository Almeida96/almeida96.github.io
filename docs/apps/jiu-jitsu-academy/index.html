React Native · Expo

Jiu-jitsu academy app.

Someone travelling for training can look up a school in the city they are visiting. The same app gives instructors a private area to invite students and keep track of belt promotions.

Mobile prototype

Engineering details ↓

Engineering details.

Each invitation is tied to an academy. The server checks the instructor’s academy before accepting a promotion, keeping student records scoped to the school that manages them.

TypeScript across mobile and web

The directory and instructor screens use React Native and Expo. Native builds keep the session token in Expo SecureStore, while the browser export keeps it in session storage.

Node.js and SQLite

The TypeScript API uses Node’s HTTP server and built-in SQLite driver. Account changes run inside database transactions so a failed operation can roll back its writes.

Invitations and access tests

An invitation specifies the academy and role the recipient can join. Tests with Node’s test runner check that a used invitation cannot be redeemed twice and a recipient cannot promote their own account.

A walkthrough

  1. Search the directory by city and open a school’s profile.
  2. Check the location and contact details, then save the school to favourites.
  3. From the instructor account, invite a student and record a belt promotion for an enrolled student.

Development status

The mobile prototype includes a browser demo for the directory and the instructor workflow.
