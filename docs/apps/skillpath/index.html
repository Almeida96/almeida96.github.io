SkillPath.

How do you tell whether free-throw practice is paying off? SkillPath turns that question into a repeatable exercise. Each session records makes out of ten from the same spot, giving the next practice a starting point.

Mobile prototype

A walkthrough

  1. Choose the free-throw challenge and take a first set of ten shots to establish your baseline.
  2. Record the number of makes and note where you stood.
  3. Repeat the set at the same distance and compare the two entries in your activity history.

Implementation

The challenge stores each attempt as its own measurement. The history keeps earlier attempts alongside the latest score, so a learner can revisit the conditions behind a change.

Development status

Free throws are one of the guided challenges in the mobile prototype. Physical-device testing is still part of the work ahead of a store release.
