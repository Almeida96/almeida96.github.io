FisioApp.

A physiotherapist selling ten-visit packages needs to record what happened and check how many visits are left after each appointment. FisioApp handles both from a desktop computer, including when it is offline.

Earlier desktop version

A walkthrough

  1. Find the patient by ID and open the session form.
  2. Write the visit notes and save the session.
  3. Open the patient history to see the notes alongside the number of visits left in the current package.

Implementation

The balance is calculated from the full session history. The tenth visit leaves zero visits in the package. Recording the eleventh starts the next package while keeping the first ten notes intact.

Development status

This is the earlier desktop application. Its records are stored locally as JSON, and the later MedApp includes an import path for those patient files.
