PC · Unreal Engine · C++

Co-op exploration game.

A shared base gives the group somewhere to prepare and somewhere to return to. Beyond the portal, players explore unfamiliar terrain together and can scan the creatures they encounter.

Unreal Engine prototype

Engineering details ↓

Engineering details

The server decides whether an explorer can take damage, checking the character’s location and state. Players at base stay protected while teammates can still be in danger outside.

C++ and Unreal networking
The scanner runs in a C++ actor component. Clients send scan input through a remote procedure call. The server checks range, aim and line of sight before accepting a target.
Private and shared state
Unreal’s owner-only replication sends scan progress and journal entries to the player who made the observation. Shared equipment, such as a portable light, has a separate network lifecycle that other players can observe.
Two-process network tests
A PowerShell harness starts separate Unreal host and client processes. The scenario cancels a scan, completes a discovery and checks what each player sees when a shared light is deployed and expires.

A walkthrough

  1. Join a co-op session and set out from the shared base.
  2. Travel through a portal and scan a creature during the expedition.
  3. Find a return portal and head back to base.

Development status

This is an Unreal multiplayer prototype. Development includes playtests with multiple game windows to check that participants see the same events.
