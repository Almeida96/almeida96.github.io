Wearloom.

A shirt photographed today can become part of next Friday’s outfit. Wearloom keeps the photograph, the garment details and the outfits that use it together on the phone.

Android preview

Engineering details ↓

Engineering details.

Once its models are downloaded, the Android preview can classify a garment on the device. The wardrobe keeps the original photo so the wearer can correct a suggestion or keep the original framing.

Mobile stack

TypeScript and React Native handle the wardrobe, outfit editor and calendar. Expo Image Picker supplies a photo from the camera or gallery, and Expo Image Manipulator compresses the image before storage.

On-device inference

On Android, an explicit recognition request loads ONNX Runtime. The CPU runs the models sequentially and releases each session after inference. If segmentation fails, the app can keep the garment category it already identified.

Local storage

AsyncStorage holds the wardrobe catalogue. Compressed photographs live in the app’s document directory. The catalogue stores portable references so it can resolve the photo paths again when the app opens.

Model integrity

A native Java module streams downloaded model files through SHA-256. Automated tests exercise the Java implementation and check the fallback for devices without the module, including interrupted reads and malformed digests.

A walkthrough

  1. Photograph a garment or pick a photo from your gallery.
  2. Review the suggested category and colour, then save the piece to your wardrobe.
  3. Combine it with other saved pieces and choose a day to wear the outfit.

Development status

The Android preview has been exercised in an emulator. Camera handling and recognition speed on a physical phone are still being evaluated.
