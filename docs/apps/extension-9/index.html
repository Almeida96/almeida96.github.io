Windows · Unreal Engine

Extension 9.

Your night shift at a guesthouse begins with a ringing phone at reception. The caller gives you a reason to leave the desk. Your notebook keeps the clues you need to decide which room to check next.

Playable Windows prototype

Engineering details ↓

Engineering details.

Each task has an in-memory checkpoint. After a capture, the player can retry the current call. Opening the notebook pauses the threat long enough to read a clue.

Unreal Engine and C++

A C++ game mode tracks incoming calls, objectives and endings. A separate HUD draws the notebook and subtitles from that state, keeping the dialogue and the current task in sync.

Visibility and collision

Before the threat can capture the player, the game traces a line from the first-person camera toward it. A wall blocking the visibility trace can interrupt an encounter in the corridor.

Audio tools

A Python script synthesizes temporary sound effects as WAV files. The telephone ring combines two tones with timed gaps, and a fixed random seed makes noisy effects repeatable across builds.

Gameplay checks on Windows

A PowerShell runner starts Unreal unattended to check checkpoints, captures and both endings. It can run the same checks against the packaged Windows build and capture frames for visual review.

A walkthrough

  1. Start a shift and answer the reception phone.
  2. Read the call, check your notebook and follow the clue into the hallway.
  3. Inspect the relevant room and return to the next call as the shift unfolds.

Development status

The Windows prototype has a playable shift with two endings. Calls use on-screen dialogue and sound effects, and a new launch begins a fresh shift.
