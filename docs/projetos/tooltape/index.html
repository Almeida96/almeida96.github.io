ToolTape.

Gravo as chamadas de ferramentas de um agente para reproduzir as respostas e revisar mudanças em um servidor MCP.

Exemplo do projeto

Detalhes técnicos

Gravação de sessões MCP
A CLI em Java 21 inicia um servidor MCP local, lista suas ferramentas e grava as chamadas solicitadas pela entrada e saída padrão. Jackson interpreta o JSON trocado pelos dois processos.
Reprodução das chamadas
O servidor avança uma posição a cada chamada correspondente. Chamadas repetidas podem devolver resultados diferentes, conforme a gravação. Uma requisição fora de ordem preserva a próxima resposta para nova tentativa.
Integridade e testes
Cada gravação inclui um checksum SHA-256 calculado sobre JSON canônico. Testes com JUnit cobrem arquivos alterados, campos ausentes ou nulos, mudanças na ordem dos arrays e o encerramento do processo após um timeout.

O problema

Um teste de agente pode falhar porque o serviço devolveu dados diferentes entre duas execuções. Para reproduzir a falha, preciso dos argumentos, das respostas e da ordem das chamadas que o agente fez.

Como funciona

O ToolTape registra uma sequência de chamadas MCP e preserva os resultados e erros em um arquivo JSON. Um servidor local reproduz a sessão gravada. Ao comparar duas gravações, o relatório mostra o caminho de cada campo alterado.

O que o exemplo mostra

Na demonstração com chamados de suporte fictícios, duas gravações das mesmas três chamadas produzem seis diferenças. No chamado INC-1042, a prioridade muda de P2 para P1 e o status passa de investigating para resolved. O relatório permite localizar os dois valores nas gravações originais.

Limites da análise

A reprodução segue a ordem e os argumentos gravados. Um agente que escolha outra ferramenta ou outra sequência precisa de um cenário próprio.

Executar o exemplo

bin/tooltape demo --dir demo-output
