FisioApp.

Depois de cada atendimento de um pacote de dez sessões, o fisioterapeuta precisa registrar como foi a consulta e saber quantas sessões restam. O FisioApp reúne essas duas tarefas no computador e funciona offline.

Versão anterior para desktop

Passo a passo

  1. Localize o paciente pelo identificador e abra o formulário de sessão.
  2. Anote como foi o atendimento e salve o registro.
  3. Abra o histórico do paciente para consultar as anotações e o saldo do pacote atual.

Implementação

O saldo vem do histórico completo de atendimentos. A décima sessão deixa o pacote com saldo zero. A décima primeira abre o pacote seguinte e preserva as anotações das dez sessões anteriores.

Estágio de desenvolvimento

Esta é a versão anterior para desktop. Os registros ficam em um arquivo JSON local, e o MedApp permite importar esses cadastros.
