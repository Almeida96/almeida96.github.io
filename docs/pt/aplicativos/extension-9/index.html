Windows · Unreal Engine

Extension 9.

O turno da noite na pensão começa com um telefone tocando na recepção. A ligação dá um motivo para sair do balcão. No caderno ficam as pistas para decidir qual quarto conferir em seguida.

Protótipo jogável para Windows

Detalhes técnicos ↓

Detalhes técnicos

Cada pendência tem um ponto de retomada em memória. Depois de uma captura, o jogador pode repetir a ligação em andamento. Ao abrir o caderno, a ameaça fica pausada durante a leitura.

Unreal Engine e C++
O modo de jogo em C++ controla ligações, objetivos e desfechos. Uma classe separada desenha o caderno e as legendas a partir desse estado, mantendo o diálogo coerente com a tarefa atual.
Visibilidade e colisão
Antes de a ameaça capturar o jogador, o jogo traça uma linha da câmera em primeira pessoa até ela. Uma parede que bloqueie essa linha pode interromper um encontro no corredor.
Ferramentas de áudio
Um script em Python sintetiza efeitos provisórios em WAV. O telefone combina dois tons com pausas programadas. Uma semente fixa permite reproduzir os efeitos que usam ruído.
Testes do jogo no Windows
Um script em PowerShell inicia a Unreal sem intervenção e verifica pontos de retomada, capturas e os dois finais. Também pode testar a versão empacotada para Windows e salvar imagens para revisão visual.

Passo a passo

  1. Comece o turno e atenda ao telefone da recepção.
  2. Leia a conversa, consulte o caderno e siga a pista pelo corredor.
  3. Inspecione o quarto indicado e volte para a próxima ligação.

Estágio de desenvolvimento

O protótipo para Windows tem um turno jogável com dois desfechos. As ligações usam diálogos em texto e efeitos sonoros. Reabrir o jogo inicia um novo turno.
