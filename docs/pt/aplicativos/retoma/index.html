Retoma.

Depois de enviar vários orçamentos na semana, o prestador precisa saber a quem retornar hoje. O Retoma organiza os contatos pela data de retorno e deixa a próxima ação junto do orçamento.

Aplicativo web com demonstração

Detalhes técnicos ↓

Detalhes técnicos.

O servidor guarda os valores em centavos inteiros e interpreta as datas no fuso de São Paulo. O total e o dia de retorno mantêm o mesmo significado quando o painel é reaberto.

React e TypeScript

O painel em React e os endpoints compartilham regras em TypeScript para valores, etapas do orçamento e datas de retorno. Vite e vinext preparam a aplicação para o ambiente Cloudflare Workers.

Consultas ao banco

O Drizzle mapeia orçamentos e configurações para o Cloudflare D1, baseado em SQLite. Um índice composto por responsável e data de retorno atende à fila cronológica de cada prestador.

Edições concorrentes

Ao atualizar um orçamento, a API inclui na operação a data de alteração que acabou de ler. Se outra requisição modificar o registro nesse intervalo, a API devolve HTTP 409.

Testes de importação

Os testes em Node.js exercitam os endpoints com um banco SQLite local. Um deles simula uma falha durante a importação em lote e verifica que os orçamentos anteriores continuam intactos.

Passo a passo

  1. Cadastre o orçamento com valor, contato e data de retorno.
  2. Abra a fila de retornos e revise a mensagem preparada para aquele orçamento.
  3. Entre em contato e registre o resultado ou marque outra data de retorno.

Estágio de desenvolvimento

O aplicativo web inclui uma demonstração com orçamentos de exemplo. As alterações dessa demonstração duram até a página ser recarregada.
