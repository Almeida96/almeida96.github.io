React Native · Expo

Aplicativo para academias de jiu-jítsu.

Quem viaja para treinar pode procurar uma academia na cidade de destino. No mesmo app, os professores têm uma área restrita para convidar alunos e registrar graduações.

Detalhes técnicos

Cada convite fica vinculado a uma academia. Antes de registrar uma graduação, o servidor verifica se o professor pertence à escola responsável pelo aluno.

TypeScript no celular e na web
O diretório e as telas do professor usam React Native e Expo. O aplicativo nativo guarda o token da sessão no Expo SecureStore. A versão web usa o armazenamento de sessão do navegador.
Node.js e SQLite
A API em TypeScript usa o servidor HTTP e o driver SQLite do próprio Node.js. Alterações de conta são gravadas em transações que desfazem a escrita se a operação falhar.
Convites e testes de acesso
O convite determina a academia e o papel de quem o recebe. Testes com o executor do Node.js verificam que o convite só pode ser usado uma vez e que o destinatário não consegue elevar as próprias permissões.

Passo a passo

  1. Busque pelo nome da cidade no diretório e abra o perfil de uma academia.
  2. Confira a localização e os canais de contato e salve a academia nos favoritos.
  3. Na conta de professor, convide um aluno e registre a nova faixa de um aluno matriculado.

Estágio de desenvolvimento

O protótipo móvel inclui uma demonstração no navegador para consultar o diretório e experimentar o fluxo do professor.
