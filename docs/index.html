API compatibility

ContractLens ↗

Compares two OpenAPI contracts and shows which declared clients use the affected operations. In the Orders example, removing express shipping from the accepted values can break a storefront request.

Query performance

PlanScope ↗

Compares exported PostgreSQL execution plans. In a sample where runtime rises from 42 to 145 ms, it flags a disk sort and a hundredfold difference between estimated and actual row counts.

PostgreSQL · SQLite · MCP

Software dependencies

BOMTrail ↗

Reads a software bill of materials to trace how a package enters an application. The example follows a shared codec through the dependency graph and lists the components that rely on it.
